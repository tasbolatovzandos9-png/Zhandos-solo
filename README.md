Java және Spring Boot технологиялары негізінде жасалған қауіпсіз пайдаланушыны тіркеу және жүйеге кіру веб-қосымшасы.
Жоба туралы

Secure Login System — пайдаланушыларды тіркеуге, жүйеге кіруге, құпиясөздерді қауіпсіз сақтауға және пайдаланушылардың рөлдеріне қарай қолжетімділікті басқаруға арналған веб-жүйе.

Жобада Spring Security көмегімен аутентификация және авторизация механизмдері жүзеге асырылған.
Жобаның негізгі мүмкіндіктері

Пайдаланушыны тіркеу.

Пайдаланушы рөлдері

Жүйеде 12 түрлі рөл қарастырылған:

ROLE_SUPER_ADMIN — бас әкімші.

ROLE_ADMIN — әкімші.

ROLE_MANAGER — менеджер.

ROLE_SENIOR_REVIEWER — аға тексеруші.

ROLE_MODERATOR — модератор.

ROLE_SUPPORT — техникалық қолдау маманы.

ROLE_ANALYST — сарапшы.

ROLE_REVIEWER — тексеруші.

ROLE_USER — қарапайым пайдаланушы.

ROLE_PREMIUM_USER — премиум пайдаланушы.

ROLE_VERIFIED_USER — расталған пайдаланушы.

ROLE_AUTHOR — автор.
